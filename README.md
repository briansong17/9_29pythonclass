# 대저그 야전교범

테란 콘솔 스타일의 스타크래프트 II 비공식 팬 교범입니다.

- 링링, 바드라, 뮤탈리스크, 가시지옥, 울트라리스크, 대군주 대응
- Supabase 공동 책갈피와 복습 기록
- 엑셀(.xlsx) 내보내기
- 첫 방문 안내 팝업

정적 HTML/CSS/JavaScript 사이트입니다. Vercel Framework Preset은 Other, Root Directory는 저장소 루트로 설정합니다. 빌드 명령은 필요 없습니다.

데이터베이스 초기 설정은 설치안내.md와 supabase-setup.sql을 참고하세요. 공개용 Supabase 키만 사용합니다.

캐릭터 및 게임 관련 권리는 원 권리자에게 있습니다. 학습 목적의 비공식 팬 프로젝트입니다.
